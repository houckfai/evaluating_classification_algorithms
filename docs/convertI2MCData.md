# `convertI2MCData.m` Documentation

## Overview

`convertI2MCData` is a post-processing helper function within Step 2 of the eye-tracking analysis pipeline. It loads sample-by-sample classification outputs generated by the **I2MC** (Identification by 2-Means Clustering) algorithm, converts gaze coordinates from screen pixel space back to normalized Tobii units, transforms spatial coordinates into screen-centered centimeter offsets, constructs a uniform time grid aligned with raw Tobii timestamps, and saves a standardized output matrix to disk.

---

## Function Signature

```matlab
[sampledData] = convertI2MCData(baseFilePath, EyeParams, ui_group_str, ...
    ui_subjectID, ui_condition_str, ui_targetSize_int, tobii)
```

## Output Specifications

### Return Value (`sampledData`)
An $N 	\times 4$ `double` matrix containing uniform sample-by-sample eye-tracking metrics:

| Column | Variable | Unit | Description |
| :---: | :--- | :--- | :--- |
| `1` | `timeSec` | seconds | Uniform time vector beginning at `tobii.time_stamps(1)`. |
| `2` | `label` | categorical integer | I2MC event classification label ($1 = 	\text{Fixation}$, etc.). |
| `3` | `x_cm` | cm | Horizontal screen-centered gaze coordinate ($0 = 	\text{screen center}$). |
| `4` | `y_cm` | cm | Vertical screen-centered gaze coordinate ($0 = 	\text{screen center}$). |

### Output File Serialization
The function creates and saves the output matrix to:
$$	\text{<baseFilePath>}/	\text{post\_step2}/	\text{<ui\_group\_str>}/	\text{i2mc\_results}/	\text{data\_<subjectID>\_<condition><sizeTag>\_i2mc\_converted.mat}$$

---

## Coordinate Transformations & Mathematical Formulations

### 1. Uniform Time Grid Construction
The uniform timestamp vector $T_{	\text{sec}}$ is derived from the initial Tobii timestamp and the hardware sampling rate $f_s$:
$$T_{	\text{sec}}(k) = t_0 + \frac{k - 1}{f_s}, \quad k = 1, 2, \dots, N$$

### 2. Pixels to Normalized Tobii Coordinates
Pixel coordinates $(X_{	\text{px}}, Y_{	\text{px}})$ are normalized relative to display resolution $(R_w, R_h)$:
$$X_{	\text{tobii}} = \frac{X_{	\text{px}}}{R_w}, \quad Y_{\text{tobii}} = \frac{Y_{\text{px}}}{R_h}$$

### 3. Normalized Units to Screen-Centered Centimeters
Normalized units $[0, 1]$ are mapped to physical screen space in centimeters $(W_{\text{cm}}, H_{\text{cm}})$, centered at the origin $(0, 0)$:
$$x_{\text{cm}} = \left( X_{\text{tobii}} - 0.5 \right) \cdot W_{\text{cm}}$$
$$y_{\text{cm}} = \left( 0.5 - Y_{\text{tobii}} \right) \cdot H_{\text{cm}}$$

> **Note**: The vertical transformation flips direction ($0.5 - Y_{\text{tobii}}$) to align screen top-left origin coordinates with standard Cartesian $(X, Y)$ axes.

## Processing Execution Workflow

```
               +-------------------------------------------------+
               | 1. Subject ID String Standardization            |
               |    - Convert numeric IDs to string chars        |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 2. File Path Resolution                         |
               |    - Resolve post_step2/i2mc_results directory  |
               |    - Construct input and output filenames       |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 3. Input Validation                             |
               |    - Verify existence of input .mat file        |
               |    - Load 'fix' structure                       |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 4. Coordinate Transformation & Time Grid        |
               |    - Construct time vector based on samplingFreq|
               |    - Normalize px to [0,1] Tobii space          |
               |    - Transform [0,1] space to centered cm       |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 5. Serialization                                |
               |    - Save [time, label, x_cm, y_cm] matrix      |
               |    - Output: data_*_i2mc_converted.mat          |
               +-------------------------------------------------+
```

## Example Usage

```matlab
% Set up project directory & hardware params
baseFilePath = 'Z:\Data\Eyetracking\pilot\yourProjectFolder';
EyeParams.samplingFreq          = 120;
EyeParams.screenResolutionWidth = 1920;
EyeParams.screenResolutionHeight= 1080;
EyeParams.screenWidthInCm       = 47.7;
EyeParams.screenHeightInCm      = 26.8;

% Set up participant parameters
groupStr   = 'G01';
subjectID  = 101;
condStr    = 'bln';
targetSize = 1;

% Call conversion function
[sampledData] = convertI2MCData(baseFilePath, EyeParams, groupStr, ...
    subjectID, condStr, targetSize, tobiiData);

% Access formatted components
time_vec  = sampledData(:, 1);
labels    = sampledData(:, 2);
gaze_x_cm = sampledData(:, 3);
gaze_y_cm = sampledData(:, 4);
```

---

## Dependencies & File Structure Requirements

* **Input File**: Expects `data_<subjectID>_<condition><sizeTag>_i2mc.mat` containing a `fix` structure (with `fix.sampleBySample`).
* **Input Data Structure**: `tobii` structure must contain a valid `time_stamps` array.
* **Directory Hierarchy**: Expects base path containing `post_step2/<group>/i2mc_results/` directory (created automatically if missing).
