# `convertRemoData.m` Documentation

## Overview

`convertRemoData` is a post-processing helper function within Step 2 of the eye-tracking analysis pipeline. It processes sample-wise classification outputs generated by the **REMoDNaV** eye-tracking event detection algorithm.

The function converts sample-wise pixel coordinates to centimeters, aligns sample timestamps with raw Tobii eye-tracking data, maps REMoDNaV's text-based event classification labels into standardized integer codes, constructs a secondary matrix remapped to match the **MNH** classification algorithm categorization scheme, and exports both matrices to a `.mat` file.

---

## Function Signature

```matlab
[sampledData, sampledData_RemoLabels] = convertRemoData(baseFilePath, ...
    EyeParams, ui_group_str, ui_subjectID_int, ui_condition_str, ...
    ui_targetSize_int, tobii)
```

## Output Specifications

The function returns two $N \times 4$ matrices and saves them to a single `.mat` file.

### 1. `sampledData` (MNH-Remapped Scheme)
Primary $N \times 4$ double matrix categorized according to the MNH classification system:

| Column | Variable | Unit | Description |
| :---: | :--- | :--- | :--- |
| `1` | `time_seconds` | seconds | Uniform time vector starting at `tobii.time_stamps(1)`. |
| `2` | `remoLabels_MNH` | integer code | Event label remapped to MNH scheme ($1= \text{Fixation}, 2= \text{Saccade}, 3= \text{PSO}, 4=	\text{Noise/Artifact}, 8= \text{Smooth Pursuit}$). |
| `3` | `x_cm` | cm | Horizontal gaze coordinate in physical centimeters. |
| `4` | `y_cm` | cm | Vertical gaze coordinate in physical centimeters. |

### 2. `sampledData_RemoLabels` (Native REMoDNaV Integer Scheme)
Secondary $N \times 4$ double matrix preserving integer versions of REMoDNaV's native string event labels:

| Column | Variable | Unit | Description |
| :---: | :--- | :--- | :--- |
| `1` | `time_seconds` | seconds | Uniform time vector starting at `tobii.time_stamps(1)`. |
| `2` | `remoIntLabels` | integer code | Native REMoDNaV integer code ($1	\text{--}9$). |
| `3` | `x_cm` | cm | Horizontal gaze coordinate in physical centimeters. |
| `4` | `y_cm` | cm | Vertical gaze coordinate in physical centimeters. |

Both matrices are saved together in a `.mat` file:
baseFilePath\post_step2\ui_group_str\remo_results\data_<subjectID>_<condition>_<sizeTag>_remo_converted.mat

## Event Label Mapping Schemes

REMoDNaV produces string-based categorical labels for each sample. `convertRemoData` converts these strings into numeric codes using two schemes:

### Scheme 1: Native REMoDNaV Integer Mapping (`remoIntLabels`)

| String Label | Code | Event Description |
| :---: | :---: | :--- |
| `FIXA` | `1` | Fixation |
| `SACC` | `2` | Saccade for Chunk Boundary Event|
| `ISAC` | `3` | Any Other Saccade |
| `LPSO` | `4` | Low-Velocity Post-Saccadic Oscillation for Chunk Boundary Event |
| `HPSO` | `5` | High-Velocity Post-Saccadic Oscillation for Chunk Boundary Event |
| `ILPS` | `6` | Low-Velocity Post-Saccadic Oscillation |
| `IHPS` | `7` | High-Velocity Post-Saccadic Oscillation |
| `PURS` | `8` | Smooth Pursuit |
| `UNKN` | `9` | Unknown |

### Scheme 2: MNH-Aligned Mapping (`remoLabels_MNH`)

To facilitate cross-algorithm comparisons (e.g., against MNH outputs), native REMoDNaV event types are consolidated into standard MNH categories:

| Native String(s) | Native Code(s) | MNH Code | MNH Category Name |
| :---: | :---: | :---: | :--- |
| `FIXA` | `1` | **`1`** | Fixation |
| `SACC`, `ISAC` | `2`, `3` | **`2`** | Saccade |
| `LPSO`, `HPSO`, `ILPS`, `IHPS` | `4`, `5`, `6`, `7` | **`3`** | Post-Saccadic Oscillation (PSO) |
| `UNKN` | `9` | **`4`** | Noise / Artifact |
| `PURS` | `8` | **`8`** | Smooth Pursuit *(preserved)* |

## Mathematical & Signal Processing Pipeline

### 1. Spatial Conversion (Pixels to Centimeters)
Gaze coordinates $(X_{\text{px}}, Y_{\text{px}})$ loaded from the REMoDNaV sample-wise table are converted to centimeters using `EyeParams.cmToPixel`:
$$x_{\text{cm}} = \frac{X_{\text{px}}}{	\text{cmToPixel}}, \quad y_{\text{cm}} = \frac{Y_{\text{px}}}{\text{cmToPixel}}$$

### 2. Time Grid Generation & Synchronization
A uniform time grid $T_{\text{sec}}$ is constructed from raw Tobii start time $t_0$ and the hardware sampling rate $f_s$:
$$T_{\text{sec}}(k) = t_0 + \frac{k - 1}{f_s}, \quad k = 1, 2, \dots, N$$

### 3. Length Discrepancy & Safety Checks
Array lengths between the reconstructed Tobii time vector and REMoDNaV sample rows are checked:
$$\text{lenDiff} = N_{\text{tobii}} - N_{\text{remo}}$$

* **Case 1: $\text{lenDiff} > 2$**: Throws a `Length difference between Tobii & REMoDNaV results` exception and terminates.
* **Case 2: $0 < \text{lenDiff} \le 2$**: Displays a warning and truncates all vectors to `minLen = min(length(timeSec), length(remoIntLabels), length(x_cm))`.

## Example Usage

```matlab
% Project directory & hardware setup
baseFilePath = 'Z:\Data\Eyetracking\pilot\projectFolder';
EyeParams.cmToPixel    = 40;  % 40 pixels per centimeter
EyeParams.samplingFreq = 120; % 120 Hz sampling rate

% Subject & trial parameters
groupStr   = 'G01';
subjectID  = 101;
condStr    = 'bln';
targetSize = 1;

% Run REMoDNaV data conversion
[sampledData, sampledData_RemoLabels] = convertRemoData(baseFilePath, ...
    EyeParams, groupStr, subjectID, condStr, targetSize, tobiiData);

% Access MNH-mapped data
time_sec   = sampledData(:, 1);
mnh_labels = sampledData(:, 2);
gaze_x     = sampledData(:, 3);
gaze_y     = sampledData(:, 4);

% Access Native REMoDNaV integer data
remo_native_labels = sampledData_RemoLabels(:, 2);
```
