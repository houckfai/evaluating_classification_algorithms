# `convertMNHData.m` Documentation

## Overview

`convertMNHData` is a post-processing helper function within Step 2 of the eye-tracking analysis pipeline. It processes classification outputs generated by the **MNH** event detection algorithm.

Specifically, the function compensates for Savitzky-Golay filter group delay, converts gaze positions from visual angle degrees back to screen centimeters, handles leading timestamp alignment with `NaN` padding, aligns sample timelines with raw Tobii timestamps, and exports a standardized output matrix to disk.

---

## Function Signature

```matlab
[sampledData] = convertMNHData(baseFilePath, EyeParams, ui_group_str, ...
    ui_subjectID, ui_condition_str, ui_targetSize_int, tobii)
```

## Output Specifications

### Return Value (`sampledData`)
An $N \times 4$ `double` matrix containing uniform, delay-corrected sample-by-sample metrics:

| Column | Variable | Unit | Description |
| :---: | :--- | :--- | :--- |
| `1` | `timeSec` | seconds | Uniform time grid starting at `tobii.time_stamps(1)`. |
| `2` | `label_corr` | categorical integer | Delay-corrected MNH event classification label. |
| `3` | `xsmo_cm` | cm | Delay-corrected smoothed horizontal gaze coordinate in cm. |
| `4` | `ysmo_cm` | cm | Delay-corrected smoothed vertical gaze coordinate in cm. |

### Output File Serialization
The output matrix is saved to:
\<baseFilePath>\post_step2\<ui_group_str>\mnh_results\data_<subjectID>_<condition>_<sizeTag>_mnh_converted.mat

## Mathematical & Signal Processing Pipeline

### 1. Savitzky-Golay Group Delay Correction
The MNH algorithm applies a Savitzky-Golay filter with a frame length $FL = 5$. This introduces a constant phase/group delay $\Delta_{\text{sg}}$:
$$\Delta_{\text{sg}} = \left\lfloor \frac{FL - 1}{2} \right\rfloor = \left\lfloor \frac{5 - 1}{2} \right\rfloor = 2 \text{samples}$$

To correct this phase shift, data vectors ($X_{\text{smo}}, Y_{\text{smo}}, \text{vel}, \text{label}$) are shifted left by $\Delta_{\text{sg}}$ samples and padded with `NaN` values at the end:
$$V_{\text{corrected}}(k) = V(k + \Delta_{\text{sg}}), \quad k = 1, \dots, N - \Delta_{\text{sg}}$$
$$V_{\text{corrected}}(k) = \text{NaN}, \quad k = N - \Delta_{\text{sg}} + 1, \dots, N$$

### 2. Visual Angle Degrees to Centimeters Transformation
MNH operates in visual degrees. Coordinates are converted back to centimeters using display scaling factors:
$$F_{\text{degToCm}} = (\text{cmToPixel}) \times (\text{pixelToDegrees}) \quad \left[\frac{\text{deg}}{\text{cm}}\right]$$
$$X_{\text{cm}} = \frac{X_{\text{deg}}}{F_{\text{degToCm}}}, \quad Y_{\text{cm}} = \frac{Y_{\text{deg}}}{F_{\text{degToCm}}}$$

### 3. Leading Sample Padding
If the initial timestamp $t_1 > 0$, missing initial samples are reconstructed to align with time $0$:
$$N_{\text{leading}} = \text{round}\left(\frac{t_1}{\Delta t} \right), \quad \Delta t = \frac{1}{f_s}$$
A synthetic leading time vector $T_{\text{leading}} = [0, \Delta t, 2\Delta t, \dots]$ is prepended, and data vectors are prepended with $N_{\text{leading}}$ `NaN` entries.

### 4. Length Alignment & Safety Validation
A uniform time vector starting at `tobii.time_stamps(1)` is generated. The array lengths are aligned using `minLen`. If the length difference between Tobii timestamps and MNH results exceeds $2$ samples, execution halts with an error:
$$\text{lenDiff} = |N_{	ext{tobii}} - N_{\text{mnh}}| > 2 \implies \text{Raise MException}$$

## Processing Execution Workflow

```
               +-------------------------------------------------+
               | 1. Subject ID & File Name Setup                 |
               |    - Convert Subject ID to char                 |
               |    - Resolve post_step2/mnh_results directory   |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 2. Input File Validation                        |
               |    - Load 'ET' structure from .mat file         |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 3. Savitzky-Golay Group Delay Correction        |
               |    - Shift vectors up by 2 samples              |
               |    - Pad trailing entries with NaN              |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 4. Spatial Coordinate Conversion                |
               |    - Divide degrees by (cmToPixel * degToPixel) |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 5. Leading Timestamp Alignment                  |
               |    - If t_1 > 0, prepend leading time grid      |
               |    - Prepend NaN padding to data vectors        |
               +-------------------------------------------------+
                                        |
                                        v
               +-------------------------------------------------+
               | 6. Tobii Synchronization & Serialization        |
               |    - Validate length diff <= 2 samples          |
               |    - Save sampledData to _mnh_converted.mat     |
               +-------------------------------------------------+
```

## Example Usage

```matlab
% Project path & parameter setup
baseFilePath = 'Z:\Data\Eyetracking\pilot\yourProjectFolder';
EyeParams.cmToPixel      = 40;     % 40 px/cm
EyeParams.pixelToDegrees = 0.0226; % 0.0226 deg/px
EyeParams.samplingFreq   = 120;    % 120 Hz

% Participant details
groupStr   = 'G01';
subjectID  = '101';
condStr    = 'bln';
targetSize = 1;

% Execute conversion
[sampledData] = convertMNHData(baseFilePath, EyeParams, groupStr, ...
    subjectID, condStr, targetSize, tobiiData);

% Extract converted columns
time_vec   = sampledData(:, 1);
event_lbls = sampledData(:, 2);
gaze_x_cm  = sampledData(:, 3);
gaze_y_cm  = sampledData(:, 4);
```

## Exception Handling & Error Conditions

1. **`MNH results file missing`**: Triggered if `data_<subj>_<cond>_mnh.mat` does not exist in `post_step2\<group>\mnh_results\`.
2. **`Variable "ET" not found`**: Triggered if the loaded `.mat` file lacks an `ET` structure.
3. **`Length difference between Tobii & MNH results: X`**: Triggered if the sample mismatch between raw Tobii timestamps and MNH vectors exceeds $2$ samples.
